# Security

This repository is a public, sanitized version of an internal reporting workflow.

It does not contain production credentials, employer names, internal email addresses, server names, network paths, proprietary dataset names, or real account data. The screenshots were redacted and relabeled before publication. The sample workbook contains fictional records only.

Do not commit a populated `.env` file. Keep credentials and environment-specific settings in environment variables or an approved secret-management service.

For a real deployment, review access controls, logging, retention, email recipients, and automated-send behavior with the appropriate security and compliance teams.
